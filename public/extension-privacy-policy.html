Dreamlab Canvas Extension Privacy Policy

Last updated: February 19, 2026

This policy describes how the Dreamlab Canvas Chrome extension handles data when users capture content from websites and save it into Dreamlab.

What Data Is Collected

  • Page metadata selected by the user (URL, title, optional preview metadata).
  • User-selected text and image references from pages.
  • User-triggered screenshot and area-recording payloads.
  • Extension settings (widget enabled state, excluded domains, capture destination).

When Data Is Collected

Data capture and transmission are user-triggered only. Collection occurs when the user explicitly invokes an action via context menu, keyboard shortcut, or extension widget button.

Rendering the floating widget on page load does not itself trigger silent capture or transmission.

How Data Is Stored and Retained

  • Extension configuration is stored in chrome.storage.local.
  • Captured items are sent to the Dreamlab web app for user-requested saving.
  • Items in Dreamlab remain until deleted by the user.

Sharing and Selling

  • Data is transferred only to Dreamlab services required to complete user-requested saves.
  • Dreamlab Canvas does not sell user data.
  • Data is not used for creditworthiness or lending decisions.

Security and Safety Controls

  • Unsupported browser/system URLs are blocked.
  • Sensitive account/payment/auth surfaces are blocked for capture workflows.
  • Metadata extraction blocks local/private/internal network targets.
  • Remote extraction paths enforce timeout and response-size limits.

User Controls

  • Enable/disable widget visibility.
  • Exclude domains from widget rendering.
  • Adjust widget position and capture destination defaults.
  • Delete saved items from Dreamlab.

Compliance details are published at /extension-data-compliance.html.
